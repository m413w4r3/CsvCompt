## Résultat du critère G0

- Les **14 invariants** ont au moins un ID de test prévu dans la matrice et au moins un ticket avec un rôle propriétaire suggéré dans le backlog; aucun ID `NEW-xx` n’est requis par le critère binaire.
- Les rôles sont des `suggested_role`, pas des personnes affectées. Si G0 exige un propriétaire nominatif, le backlog ne le fournit pas encore.
